# Pakistan-economic-analysis
This interactive dashboard transforms complex economic data into clear, actionable insights by examining: 🔹 GDP growth and recovery trends  🔹 Inflation patterns and economic pressure periods  🔹 Unemployment trends and post-COVID impact  🔹 Correlation analysis between key economic indicators
## 📊 Overview
An interactive Power BI dashboard analyzing key economic indicators of Pakistan 
from 2018 to 2024, including [GDP growth, inflation, trade balance, unemployment, 
exchange rates, etc.]. The project aims to visualize trends over this period and 
provide actionable insights into Pakistan's economic performance, including the 
impact of major events like the COVID-19 pandemic and recent economic instability.

## 🎯 Objectives
- Analyze trends in [GDP, inflation, exports/imports, etc.] from 2018 to 2024
- Identify correlations between key economic indicators
- Highlight the economic impact of major events (e.g., COVID-19, currency devaluation)
- Provide a clear, interactive view of Pakistan's economic health for stakeholders/researchers

## 🗂️ Dataset
- **Source:** [e.g., World Bank, State Bank of Pakistan, Pakistan Bureau of Statistics, Kaggle]
- **Time period:** 2018–2024
- **Key variables:** GDP, inflation rate, exchange rate, unemployment rate, exports, imports, etc.
